# NOTE ON LDNOOBW_V2
#   LDNOOBWV2/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words_V2 (CC0-1.0) was
#   evaluated as a replacement source and REJECTED for bulk application: its aggregated
#   English list flags ordinary vocabulary such as "church", "faith", "food", "beach",
#   "blind", "attack", "stroke", "acumen" and "virgin". Applying it wholesale would make
#   those words unguessable. A hand-reviewed subset of genuine slurs and explicit terms

#
# TIERS
#   [severe]  Removed from BOTH the guess-validity list and the answer pool.
#             Slurs, explicit sexual content, and sexual-violence terms.
#   [mild]    Remains a VALID GUESS; removed from the answer pool only.
#             Mild profanity and clinical/anatomical vocabulary. Players type rude words
#             to probe a new game, and rejecting a real word as "not a word" reads as
#             broken -- but a wellness app must never serve one as the word of the day.
#
#   A term listed in [mild] takes precedence over the same term in [severe].
#   Matching is WHOLE-WORD, so substring false positives (the Scunthorpe problem) cannot
#   arise. Multi-word phrases are retained for fidelity to the source; they never match a
#   single dictionary word.
#
#
#   Some [mild] entries were added after cross-checking the generated answer pool against
#   the LDNOOBWV2 aggregate: sexual and anatomical vocabulary that is unremarkable in a
#   dictionary but wrong as a wellness app's word of the day. They remain valid guesses.
#   That cross-check was a REVIEW AID only; the aggregate is not applied automatically.
#
#   Deliberately NOT swept here: violence, grief, illness, self-harm and body-image
#   vocabulary. Those categories are context-sensitive, and half-automating them would
#   give a false impression of coverage. They belong to the human sign-off pass below.
#
# HUMAN SIGN-OFF REQUIRED
#   This list is NOT sufficient on its own. The generated answer pool still needs a human
#   review pass before launch -- automated blocklists do not catch context-sensitive
#   entries that are unremarkable in a dictionary and wrong as a wellness app's word of
#   the day (grief, illness, self-harm and body-image vocabulary in particular).
